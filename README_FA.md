# Craftoria Telegram Bots

پروژه شامل دو ربات مستقل است:
- `main.py`: ربات مشتریان
- `admin.py`: ربات مدیریت چندادمینه

## نصب
Python 3.10 یا جدیدتر لازم است.

```bash
pip install -r requirements.txt
```

فایل `.env.example` را به `.env` تغییر نام دهید و مقادیر را تنظیم کنید:
- `MAIN_BOT_TOKEN`: توکن ربات اصلی از BotFather
- `ADMIN_BOT_TOKEN`: توکن ربات مدیریت از BotFather
- `ADMIN_IDS`: آیدی عددی ادمین‌ها، جداشده با کاما
- `CARD_NUMBER`: شماره کارت مقصد
- `SUPPORT_USERNAME`: آیدی پشتیبانی بدون @

## پیدا کردن آیدی عددی ادمین
هر ادمین می‌تواند به یک ربات نمایش‌دهنده Telegram ID پیام دهد و عدد شناسه خود را در `ADMIN_IDS` قرار دهد.
هر ادمین باید حداقل یک‌بار ربات مدیریت را Start کند تا ربات بتواند برایش پیام بفرستد.

## اجرا
دو پردازش جداگانه در دو ترمینال اجرا کنید:

```bash
python main.py
```

```bash
python admin.py
```

هر دو پردازش باید در یک پوشه و روی یک میزبان اجرا شوند تا به فایل دیتابیس `craftoria.sqlite3` مشترک دسترسی داشته باشند.

## جریان سفارش
1. مشتری نام، تلفن و تصویر آیتم را می‌فرستد.
2. سفارش و عکس برای همه ادمین‌های تعریف‌شده ارسال می‌شود.
3. ادمین تأیید یا رد می‌کند.
4. در صورت تأیید، ادمین قیمت را در گفت‌وگوی ربات مدیریت وارد می‌کند.
5. قیمت و شماره کارت برای مشتری ارسال می‌شود.
6. مشتری تصویر رسید را به ربات اصلی می‌فرستد؛ رسید برای ادمین‌ها ارسال می‌شود.
7. مشتری آدرس دقیق را وارد می‌کند و پیام ثبت آدرس دریافت می‌کند.

## نکات مهم
- توکن‌ها و شماره کارت را در مخزن عمومی یا گروه‌ها منتشر نکنید.
- برای امنیت، فایل `.env` را در Git قرار ندهید.
- قبل از استفاده واقعی، با سفارش آزمایشی و مبلغ غیرواقعی تست کنید.
- این نسخه تأیید خودکار پرداخت بانکی ندارد؛ رسید فقط برای بررسی دستی ادمین ارسال می‌شود.
